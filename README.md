# 🔍 FitNet - Overfitting & Underfitting Detective System

An interactive web application that helps you understand, detect, and fix overfitting and underfitting in neural networks.

## 🎯 Features

- **6 Different Neural Network Models** to demonstrate overfitting/underfitting
- **Interactive Training** with adjustable parameters
- **Real-time Visualization** of training progress
- **Comprehensive Comparison** of regularization techniques
- **50,000 Sample Dataset** for reliable results
- **Beautiful Web Interface** built with Streamlit
